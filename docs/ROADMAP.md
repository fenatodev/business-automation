# Roadmap

This roadmap is a direction, not a rigid commitment. It can be refined with evidence from real use.

## NOW

- Consolidate the current backend.
- Ensure reproducible migrations.
- Protect data integrity.
- Keep tests reliable.
- Prepare multi-tenant architecture.
- Evolve Company as a real configuration unit.
- Validate the basic Company → Lead → Customer → Conversation → Message flow.

## NEXT

- Add agent configuration by Company.
- Add authentication and users.
- Add authorization/RBAC and actual tenant isolation.
- Improve CRM and lead/customer lifecycle.
- Support real Client 0 and first external-client flows.
- Add integrations required by those validation cases.

## LATER

- RAG and per-company knowledge bases.
- More advanced automations; use n8n where appropriate.
- More complete analytics.
- Billing/subscriptions.
- Self-service SaaS.
- Additional channels.
- Advanced marketing features.
